# Evidence Screenshots

This folder contains screenshots captured during the Windows Event Viewer investigation lab.

Screenshots provide visual evidence of the investigated Windows Security events.

## Events Covered

- Event ID 4625 — Failed Logon
- Event ID 4624 — Successful Logon
- Event ID 4672 — Special Privileges Assigned
- Event ID 4720 — User Account Created

Sensitive information such as usernames, IP addresses, and personal details should be redacted before publishing.
